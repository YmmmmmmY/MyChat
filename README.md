# 仿微信即时通讯 Android 客户端
> 课程项目，基于Java开发的仿微信UI即时通讯客户端

## 技术栈
- 语言：Java
- 开发工具：Android Studio
- UI：XML布局、RecyclerView实现会话列表
- 核心：多线程异步、网络请求、数据解析、本地存储
- 版本管理：Git

## 功能说明
1. 多Tab页面：会话、联系人、我的页面
2. 会话列表展示，理解RecyclerView复用机制，关注列表滚动性能
3. 多线程异步网络通信，避免阻塞主线程.
3. 多线程异步网络通信，避免阻塞主线程.
4. 本地缓存用户信息
5. 基础分辨率适配，修复界面交互缺陷
